# Rune Dice 复刻功能清单

> 配套文档：《RuneDice_复刻策划案》
>
> 状态约定：`待确认` / `待开发` / `开发中` / `待验收` / `已完成` / `暂缓`
>
> 优先级：P0 为垂直切片必需，P1 为单局闭环必需，P2 为内容扩展，P3 为长期完善。
>
> 阶段签收：功能状态全部完成不代表阶段自动完成。阶段必须通过《RuneDice_阶段交付与验收标准》的交付门槛，并由用户明确签收。
