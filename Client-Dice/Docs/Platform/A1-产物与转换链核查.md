## 0. 一句话判定

`Builds\WxMiniGame` **不是微信小游戏包，而是团结引擎（Tuanjie）WebGL 构建的中间产物**；它缺少 `game.js` / `game.json` / `project.config.json`，**无法导入微信开发者工具**。产出完整小游戏包需要的不是再跑一次现用的构建脚本，而是改走 **「MiniGame 平台 + 微信子平台激活 + Build Profile」** 这条官方转换链。

**结论分级：`WebGL 中间产物，缺转换步骤`。**

### 2.6 我推断（明确标注为推断）

1. 本次构建**没有激活微信子平台**（未走 Build Settings/Build Profile 流程），因此**未启用 `MINIGAME_SUBPLATFORM_WEIXIN` 宏、未执行 WebGL→小游戏 的「导出并转换」**，只落了 WebGL `Default` 模板产物。

## 3. 缺转换：确切可执行步骤（照抄即可）

### 3.1 前置：引入微信小游戏转换 SDK（二选一）

- **A. git 方式**（推荐）：`Window → Package Manager` → 左上 `+` → `Add package from git URL…`，填：
  ```
  https://github.com/wechat-miniprogram/minigame-tuanjie-transform-sdk.git
  ```
  （需本机已配置 Git。）
- **B. 下载插件导入**：下载「微信小游戏转换SDK插件」压缩包并导入工程。完成后 `Assets/` 下应出现 **`WebGLTemplates`** 与 **`WX-WASM-SDK`** 两个文件夹（见 `WechatSDK.html` L146）。

> 若走编辑器 UI 首次切平台时已自动装好子平台包，可跳过本节；判别法：`File → Build Settings → MiniGame → Sub Platforms` 一行若显示 **“Add Build Profile”** 即已就绪，若显示 **“Install Support”** 则先点它安装。

同时确保 **WebGL 平台模块**（WebGLSupport）已随 WeixinMiniGame 模块一并安装（文档多处要求）。项目自带的 `Assets\Editor\WeixinMiniGameBuild.cs` 是**旧式入口，不能产出小游戏包**，请勿依赖它。

### 3.2 编辑器 UI 路径（最稳，推荐）

1. `File → Build Settings` → 平台列表选 **MiniGame** → 点 **Switch Platform**。
2. `Sub Platforms` → 选 **微信小游戏** → 若为 **Install Support** 先安装；否则点 **Add Build Profile**。
   → 生成 Build Profile 资产于 `Assets/Settings/Build Profiles/*.asset`。
3. 选中该 Build Profile，在 Inspector：
   - **Build Data**：填写 **Build Path**（有效路径，如 `D:\NewOne\Client-Dice\Builds\WxMiniGame_Weixin`）。
   - **MiniGame Platform Settings / project conf**：点 **微信小游戏转换平台 → 更多配置项**（或 `扩展菜单 → debug`）配置 `appid` 等（`project.config.json` 的来源）。
4. 激活微信子平台（`Inactive/Active`，同时只能激活一个）。
5. 勾选该 Build Profile 左侧小框 → 点右下 **Build**。
6. 产物即为小游戏工程目录（文档口径为 **`wechat/minigame`**），用微信开发者工具以 **Mini Game** 类型 **import** 导入。

## 4. 风险与未决

1. **转换 SDK 的来源与联网**：`WechatSDK.html` 称「默认集成/自动安装」，但本机引擎目录与工程三处均查无该 SDK。无法在本沙箱验证「切换平台时自动安装」是否需联网或需 UI 交互。**未决**。
2. **`-minigamesubplatform` 与 `BuildPipeline.BuildMiniGame` 未实测**：二者均出自官方文档，本沙箱禁跑构建，未获运行时验证。**未决**。
3. **输出目录名**：文档口径为 `wechat/minigame`；本项目现用脚本把路径改写为 `Builds/WxMiniGame`。转换成功后输出到何处需以实测为准。**未决**。
4. **旧入口是否可复用**：证据表明 `BuildPipeline.BuildPlayer(BuildTarget.WeixinMiniGame)` 产出的是 WebGL 中间产物，**不能**直接产出小游戏包。若要自动化，须新增 §3.4 的 Build Profile 入口。
5. **Tuanjie 1.1.0 兼容性提示**：`WechatSDK.html` L162 指出 Tuanjie 1.1.0 自带转换插件与项目不兼容，需卸载并删 `Assets` 下的 `WebGLTemplates`/`WX-WASM-SDK-V2` 后装旧版。当前为 1.10.2，暂按最新版处理，但若 §3.1 安装后报错，按该条回退。
6. **与既有结论的冲突**：需修订 `Assets/Editor/WeixinMiniGameBuild.cs` 头注释中「不需要转换 SDK」的表述（本次不改文件，仅提示）。
