# 演示阶段丙：多骰碰撞与同级合并

## 本阶段交付目标

在原作森林牌桌上交付可连续操作的多骰系统：多枚完整三维骰子能够连续投掷并保留在桌上，停稳后稳定占位，骰子之间使用真实三维碰撞；两枚同等级骰子发生接触时，消耗原骰并生成一枚高一级骰子。

## 已实现内容

- 直接复用阶段甲的原作森林牌桌、静态边界和掉落触发区域。
- 直接复用阶段乙的原作九级三维骰子、六面结构、修复材质与三维刚体参数。
- 保留原作牌桌视觉与原作边界资源；为导出资源中不稳定的桌面碰撞补充阶段丙独立物理碰撞层，并将掉落检测限制在牌桌下方，避免高位投掷被误判掉落。
- 每枚骰子均拥有独立的 `Rigidbody` 与 `BoxCollider`，不是复制图片或播放假旋转。
- 可连续投掷，场上最多保留十二枚骰子；已有骰子不会因下一次投掷而被复位。
- 骰子低速持续零点七五秒后进入停稳状态并由物理引擎休眠；受到后续碰撞时会再次参与解算。
- 骰子之间可发生真实碰撞、反弹和挤压，占用各自空间。
- 同等级且低于九级的两枚骰子接触后合并为高一级骰子；异级骰子和两枚九级骰子不合并。
- 合并结果在两枚原骰的接触中点生成，并带有轻微弹起和翻转反馈。
- 掉出牌桌的骰子会被回收并计数，不影响其余骰子。
- 提供稳定可重复的“同级碰撞合并”演示按钮，以两枚一级骰子的相向物理运动验证合并链路。
- `DemoCDie` 与 `DemoCFallDetector` 使用独立脚本资源，避免团结引擎场景序列化时将多类脚本误识别为缺失脚本。
- 游戏内标题、交付目标、状态、按钮和操作提示均使用中文。
- 骰子六个面的数字使用参与深度测试的三维字体材质：可见面的数字显示，背面数字由骰子表面正确遮挡。

## 操作方式

- 点击“投掷选中等级”或按空格键：投掷一枚当前等级骰子。
- 点击“降低投掷等级”或按左方向键：选择低一级骰子。
- 点击“提高投掷等级”或按右方向键：选择高一级骰子。
- 点击“同级碰撞合并”或按回车键：清空桌面并启动两枚一级骰子的相向碰撞验收。
- 点击“清空牌桌”或按删除键：移除所有场上骰子。

## 统一验收步骤

1. 启动 `Builds/Demo-C/Windows/RuneDiceDemoC.exe`。
2. 检查开场三枚不同等级骰子是否分别稳定占位。
3. 连续投掷至少六枚骰子，确认前一枚不会被后一枚替换，且飞行时能看到完整立方体的不同侧面和边角。
4. 观察骰子落桌后彼此碰撞、反弹、逐渐停稳并保留各自空间。
5. 点击“同级碰撞合并”，确认两枚一级骰子相向移动、发生接触，然后生成一枚二级骰子；合并次数变为一。
6. 分别投掷一级和二级骰子，确认异级接触不会合并。
7. 将骰子投出桌外，确认掉落计数增加而其他骰子不被重置。
8. 检查画面内所有界面说明是否为中文。

## 通过标准

- 场上可同时存在至少六枚独立三维骰子，且每枚都有真实位置、旋转和碰撞。
- 连续投掷不会重置或替换已落桌骰子；最大容量为十二枚。
- 骰子能逐渐停稳并稳定占位，后续骰子撞击时可再次响应。
- 同级接触后数量由二变一、等级加一；异级和九级不合并。
- 合并必须由骰子碰撞触发，验收按钮只负责生成相向运动的同级骰子。
- 牌桌、骰子模型、九级视觉及物理基线均来自原项目资源。
- 无二维刚体和固定图片旋转方案。
- 自动化测试全部通过（32/32），实机日志出现 `DEMO_C_RUNTIME_OK`、真实碰撞记录与 `DEMO_C_SMOKE_OK`。
