# 符文骰子复刻工程

这是一个使用团结引擎 1.10.2（Unity 2022.3.62t14）创建的独立复刻工程。目前包含 M0 物理合并原型和 M1 战斗垂直切片。

## 运行

1. 使用团结引擎 1.10.2 打开本目录。
2. 打开 Assets/Scenes/BattleM1.unity。
3. 点击 Play；或直接运行 Builds/M1/Windows/RuneDiceM1.exe。

## 操作

- 生成点会显示圆盘瞄准 UI：按住中心圆形按钮并在圆盘内拖拽，骰子会向拖拽的反方向投掷；拖拽距离对应力度，拖到圆盘边缘时落点刚好到达棋盘边缘。
- 拖拽过程中会持续显示带上扬弧度的抛物线轨迹，松开中心按钮后投掷下一枚骰子。
- 同类型、同等级骰子碰撞后合并；合并按发生顺序进入结算队列。
- 攻击骰伤害敌人，治疗骰恢复生命，护盾骰抵消敌方伤害。
- F10：打开/关闭 M1 验收模式，可载入 M1-A～M1-G 固定场景。
- Esc：先关闭验收面板，再次按下退出游戏。

M0 原型仍保留在 Assets/Scenes/DiceMergeDemo.unity，仅用于回看早期物理玩具，不参与 M1 构建。

## 资源来源

背景、Logo、骰子和角色贴图来自 Rune Dice 的 AssetRipper 导出工程。Demo 逻辑为独立重写，不依赖导出工程中的空壳脚本或第三方 DLL。
