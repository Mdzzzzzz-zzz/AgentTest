# Demo-A：原作牌桌基线

## 交付目标

建立后续三维骰子玩法使用的牌桌空间基线，不包含骰子投掷与合并玩法。

- 复用原作 `Desk Base - Forest` 森林牌桌资源。
- 使用原作正交相机参数：尺寸 12，位置 `(0, 24.47, -20.89)`，俯角约 33 度。
- 使用三维物理，重力为 `(0, -30, 0)`。
- 保留 4 个有效静态边界和 2 个前方掉落触发器。
- 保留并可视化原作 85 个桌面预生成点。
- 游戏内验收信息全部使用中文。
- 与旧二维 Demo 完全隔离，Demo-A 运行时不得产生 `Rigidbody2D`。

## 测试方法

1. 运行 `Builds/Demo-A/Windows/RuneDiceDemoA.exe`。
2. 确认画面是木质森林牌桌，不是像素风背景图。
3. 确认右上角不存在旧 Demo 的“投掷”和“重新开始”按钮。
4. 确认场地内可看到 85 个青色预生成点标记。
5. 确认左上中文面板显示：相机尺寸 12、重力 -30、静态边界 4、掉落触发器 2。

## 通过标准

- Demo-A 自动测试 4/4 通过。
- 工程全部编辑器测试 19/19 通过。
- 运行日志出现：`DEMO_A_RUNTIME_OK 三维牌桌已独立启动，二维刚体=0，相机=1`。
- 运行截图中无旧二维背景、二维骰子和旧操作按钮。
