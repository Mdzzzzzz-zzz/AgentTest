# M1.1.0 三维战斗切片变更记录

## 新增

- 战斗骰子改为复用原作九级三维骰子视觉模板。
- 每枚战斗骰子使用三维 `Rigidbody`、`BoxCollider` 和原作橡胶物理参数。
- 保留原作六面数字的深度遮挡表现，背面数字由骰体正确遮挡。
- 投掷、旋转、反弹、停稳、碰撞和同级合并全部走三维物理链路。
- 战斗场景生成器改为从阶段丙场景复用牌桌、物理层、骰子模板和数字材质。

## 修改

- M1 战斗场景从二维正交骰子表现改为原作森林牌桌上的三维骰子战斗表现。
- 瞄准线改为牌桌平面上的三维投掷目标。
- 版本号更新为 `M1.1.0-三维战斗开发版`。
- 游戏内可见文案继续保持中文。

## 未改变

- 七阶段回合状态机、攻击/治疗/护盾效果、敌方意图和验收模式规则保持不变。
- 原有 M1 规则自动测试继续保留。
